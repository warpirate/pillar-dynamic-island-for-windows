Everything in one pill

Glanceable. Native. Out of the way.

Hover to peek, click to expand. PILLAR stays invisible until you need it.

🎵

Media controls

Play / pause, skip, scrub and see what's playing across any app — read straight from Windows SMTC.

⏱

Focus timers

Pomodoro-style timers with a progress ring on the pill and a desktop alert when time's up.

🔔

Notifications

Live notification toasts that fold into the pill, with a scrollable history you can clear.

🔊

Volume & devices

System volume, per-app mixer, output device switching and brightness — without opening Settings.

🤖

Prism AI

An assistant that can read your context and run actions — start a timer, change volume, more.

✓

Focus & tasks

Quick tasks, notes and an agenda in a tidy productivity tab, backed up locally.

Get started

Up and running in a minute

STEP 1

Download the installer

Grab the latest .exe (or .msi) from GitHub Releases — no account needed.

STEP 2

Run it

Windows 10/11. If SmartScreen appears, choose “More info → Run anyway” (unsigned open-source build).

STEP 3

Look up

The pill appears at the top-center of your screen. Hover to peek, click to expand.
