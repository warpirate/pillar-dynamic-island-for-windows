Why PILLAR

Built the way a desktop tool should be.

◎

Free forever

No subscription, no paywalled AI, no account. Bring your own key for Prism.

⛨

Private by design

AI context is app title + name only. No screenshots, no telemetry, nothing leaves your machine.

⌥

Open source

MIT licensed. Read every line, file issues, send PRs — it's all on GitHub.

⚡

Featherweight

~3 MB, Rust backend, adaptive polling that sleeps when idle. Built on Tauri 2.

Install

Running in under a minute.

Download

Grab the latest .exe (or .msi) from GitHub Releases — no sign-up.

Run it

Windows 10/11. If SmartScreen appears, hit More info → Run anyway — it's an unsigned open-source build.

Look up

The pill appears top-center. Hover to peek, click to expand. That's it.
